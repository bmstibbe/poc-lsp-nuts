# 11. Summary

-   Goal: A standardized, verifiable trust layer between Nuts and the
    LSP.

-   Standards: W3C VC v2.0, OID4VCI, JWT-VC, OAuth 2.0, FHIR R4,
    PKIoverheid/Nuts certificates.

-   Key Concepts: Separation of identity (authentication), attributes
    (VC), subject/holder, and interoperability.
