# 1. Introduction
This document describes the technical standards and use of Verifiable Credentials (VCs) and FHIR for exchanging patient and healthcare provider data between the Nuts network and the LSP.

**Objectives:**
- Ensure interoperability with existing wallets, issuers, and verifiers.
- Avoid creating a proprietary “Nuts–LSP VC format”; align with recognized international standards.
- Prepare for future implementations such as DEZI.
